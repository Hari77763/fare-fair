# Reference data licences

These files are generated by `npm run data:refresh` (`scripts/build-reference-data.mjs`).

## airports.json

Derived from [OurAirports](https://ourairports.com/data/) `airports.csv` and
`countries.csv`, which are released to the **public domain**. Time zones are
computed from coordinates with [tz-lookup](https://github.com/darkskyapp/tz-lookup-oss)
(CC0-1.0). Only airports with an IATA code and scheduled service are included.

## airlines.json

Derived from the [OpenFlights](https://openflights.org/data) airline database,
made available under the **Open Database License (ODbL) 1.0**
(https://opendatacommons.org/licenses/odbl/1-0/). Individual contents are under
the Database Contents License (DbCL) 1.0.

This derived database (`airlines.json`) is likewise made available under the
ODbL 1.0. Attribution: © OpenFlights contributors.

FairFare's hand-curated names in `src/lib/fares/airlines.ts` take precedence
over this file where OpenFlights is out of date.
